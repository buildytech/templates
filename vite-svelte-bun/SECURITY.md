# Security policy

## Supported versions

Security fixes are applied to the latest stable release. Template applications
are source starters: after creating a project, keep its dependencies updated.

## Reporting a vulnerability

Do not open a public issue for a suspected vulnerability. Use GitHub private
vulnerability reporting in this repository and include reproduction steps,
affected versions, and expected impact. Maintainers will acknowledge a complete
report within five business days.

Never include credentials, private source, prompt content, or personal data in
a report.
