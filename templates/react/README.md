# React 19 starter

Mobile-first one-page site on Vite, React 19, Tailwind 4 and UI8Kit primitives: header with navigation, mobile Sheet menu,
dark mode, hero, features, call to action and footer. Content in `src/fixtures/*.json`, interface words in
`src/i18n/en.json`. Local Istok Web font, favicon set. No backend.

```sh
bun install
bun run dev
bun run verify
```

Rules for agents and humans: [AGENTS.md](AGENTS.md) and `.cursor/rules` (from ui8kit/contract).
